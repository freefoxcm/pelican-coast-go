# 🦩 海岸拾光 · 追鱼 — Pelican Coast Go

一只**戴红色骑行头盔、黑色墨镜、脖子系红围巾的鹈鹕**，在黄昏的海岸公路上骑复古自行车抓鱼。
从金色黄昏一路骑到星空月夜：围巾是真实布料模拟，音乐与音效全部由浏览器实时合成，节奏跟着踏频走。

## ▶ 在线试玩

**https://freefoxcm.github.io/pelican-coast-go/**

> 首次点击「出发」后浏览器才会解锁音频（自动播放策略）。
> 不想操作也可以：1.8 秒无输入后自动进入自动驾驶，它会自己变道、起跳、追鱼。

## 玩法与操作

| 按键 | 作用 |
|---|---|
| `W` / `S` | 加速 / 减速（0 ~ 122 km/h） |
| `A` / `D` | 变道，对准跃出水面的鱼 |
| `空格` | 跳跃（高抛鱼要跳起来才够得到） |
| `T` | 展翅 + 抬前轮（耍帅，附加速） |
| `C` | 切换 5 种镜头 |
| `K` | 14 项成就面板 |
| `M` / `P` / `R` | 静音 / 暂停 / 重新开始 |

触屏设备（或 `?touch=1`）会自动显示虚拟按键：变道、加速减速、跳跃、展翅、镜头、静音。

## 特性

- **鹈鹕骑手**：程序化建模 —— 红色骑行头盔（通风槽/白中脊/帽檐/后调节扣）、镀膜运动墨镜、长喙与可动喉囊、**双手（翅手）双骨 IK 始终握在车把上**、两段式腿带膝弯 IK 踩踏、216 质点 Verlet 布料红围巾
- **5 种镜头**：追尾（弹簧跟随 + 速度 FOV）、电影运镜（8 个自动机位硬切推拉 + 电影黑边）、鹈鹕视角（第一人称，可见喙尖与双手握把）、海侧长焦、高空航拍
- **14 个成就**：初次展翅 / 一跃而起 / 空中飞鱼 / 大胃王 / 鱼贯而入 / 风驰电掣 / 夜行者 / 星空漫游 / 围巾狂舞 / 完美落地 / 电影明星 / 摄影指导 / 自动驾驶 / 海岸马拉松
- **昼夜循环**：240 秒一轮，金色黄昏 → 洋红日落 → 蓝调 → 星空月夜 → 拂晓；方向性晚霞、2500 颗星、银河、月盘、路灯与灯塔点亮
- **海面**：Gerstner 波 + 解析法线 + 菲涅尔 + 日月反光带 + 近岸碎浪泡沫 + 夜间生物荧光
- **实时音频**：零音频文件，Web Audio 合成 Am–F–C–G 16 小节循环 + 海浪风声 + 8 种 ADSR 音效；**BPM 跟随踏频**（72–152）
- **画质自适应**：按帧率自动调整像素比 / 海面细分 / 阴影 / Bloom / 星空数量，桌面 60 FPS

## 技术

- 纯静态 **ES Module + Three.js r169**，无打包器、无外部图片/音频资源（全部程序化生成）
- 后处理：EffectComposer + UnrealBloomPass + OutputPass（内置 NaN/Inf 兜底，避免单个坏像素污染全屏）
- Three.js 通过一个小引导器从多个镜像加载（国内 CDN 优先），校验响应完整性后动态注入 importmap —— 因此可直接部署在任意静态主机与子路径下
- 触屏 / 键盘双输入、`prefers-reduced-motion` 适配

## 本地运行

```bash
# 任意静态服务器即可，例如：
npx serve .
```

打开 `http://127.0.0.1:3000/`（或你使用的端口）。
页面参数：`?quality=0|1|2`、`?day=0.5`、`?camera=pov`、`?touch=1`、`?autostart=1`、`?ui=0`。
